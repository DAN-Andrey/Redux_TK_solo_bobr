# Redux Toolkit: соло-практика (Fullstack)

Fullstack-приложение для отработки навыков работы с **Redux Toolkit** на React и **Express** на бэкенде.

---

## 🛠️ Стек

**Frontend:** React, TypeScript, Redux Toolkit, Vite  
**Backend:** Node.js, Express, PostgreSQL

---

## 📱 Что умеет

- Добавление, удаление, редактирование сущностей
- Фильтрация списка
- Асинхронные операции (работа с API)
- Данные сохраняются в PostgreSQL
